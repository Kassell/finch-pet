# Flappy Bird audio assets

Files in this directory are extracted sound effects associated with the original Flappy Bird game:

- `die.ogg`
- `hit.ogg`
- `point.ogg`
- `swoosh.ogg`
- `wing.ogg`

Source mirror: https://github.com/samuelcust/flappy-bird-assets

Flappy Bird was created by Dong Nguyen / .GEARS. These audio assets are included at the project owner's direction.
